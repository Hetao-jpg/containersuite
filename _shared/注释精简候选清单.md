## 2. 分类规则（五问法落地 + 项目红线）

- **删除档**：明天消失无人受损；且能 `git log -S` 复原。→ 纯来源/沿革注释、已删实现说明、自我否定块。
- **搬迁档**：背景/取证/决策理由，≥ ~10 行且不含"当前行为描述"。→ 逐字搬 `docs/*.md`，源码留 1~3 行指针。
- **保留档（红线，不删不搬）**：
  1. 任何含 `0x80131506` 的注释（45 处）。
  2. 不变量/契约：`刻意不…`、`必须…`、`禁止…`、`唯一权威默认值写在这里`、`保持无条件`、`不成立/会静默失效` 的设计判据。
  3. 门禁/回归契约：`[REG]` 输出格式、`regress.ps1` 哨兵行、R1~R8 相关字段名。
  4. 玩家可见告警、跨 mod 外部契约（key 给别家读）。
  5. 铁律 L1~L10 的就地实例（PollThrottle / CacheLimits / CacheRegistry / ShouldDefer / CfgKeys 字面量禁令等）。
