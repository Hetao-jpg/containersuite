## 三、任务 2：每容器 id 独立上限（新键 `8A_PerIdSizeLimits`）

**实现**：`ContainerSuite.DIYUpgrade/DiyUpgradeMod.PerIdLimits.cs`（新文件）

```
8A_PerIdSizeLimits = "storage_bay=30x20, evidence_box=24x24"
```

- 一项 `容器id=宽x高`，分隔符认逗号 / 中文逗号 / 分号
- 数字范围 1~100，与 `TryGetGridShapeLimits` 的 `HardMaxDim` 对齐
- **写了就完全覆盖**它所属分类的 `7x_` 上限（可增可减）；没写的继续用分类上限
- 它是字符串项 ⇒ ModManager 面板里看不见（面板只显示 bool / 数字 / Hotkey），只能手改 cfg —— 这是刻意取舍，
  理由见文件头注释：容器 id 是开放集合，给 200 个已知 id 各建两条会把 cfg 变成 400 行噪音
- **改完不用重启**：`OnEntryValueChanged` 里重解析 + 作废 `_resizableCache` / `_prepareCache`
- 解析失败 → **保留上一次生效的设置**并告警，绝不因为写错一个字符就让所有容器上限一起失效
- 启动 Summary **无条件输出**（不进 DiagLog 闸门）：
  `[容器升级] 单独设了上限的容器共 N 件：storage_bay=30x20（储藏区）…`
  一条没配就打「没有为单个容器单独设上限」—— 这是"我改了配置怎么没生效"的第一现场

三层覆盖关系（自上而下，越下越强）：

```
7x_<类别>MaxW/MaxH   ← 玩家最常用，面板可改
      ↓ 被覆盖
8A_PerIdSizeLimits   ← 单个容器 id，位置在配置末尾
      ↓ 被覆盖
硬边界 1~100         ← 谁也写不出去
```
